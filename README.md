# Butterfly Gathering – Ludum Dare 58 Project

**Butterfly Gathering** – это игра, разработанная за 48 часов в рамках Ludum Dare 58. Проект создан на Unity и демонстрирует эффективное использование современных инструментов и подходов для быстрой разработки.

---

## ✨ Ключевые особенности

- **Локализация** – поддержка нескольких языков через Unity Localization, что позволяет легко адаптировать игру под разные регионы.
- **Асинхронные операции** – с использованием UniTask для написания чистого и производительного кода без корутин.
- **Плавные визуальные эффекты** – анимации и переходы реализованы с помощью DOTween.
- **Сетевое взаимодействие** – отправка и получение данных через HTTP (GET/POST запросы) для таблицы лидеров.
- **Профессиональный звук** – интеграция FMOD для создания динамичного аудиоконтента; разработан собственный инструмент генерации кода на основе ресурсов FMOD, что позволяет обращаться к звукам через строго типизированный класс `AudioSystem` и упрощает разработку.

---

## 🛠 Используемые технологии и пакеты

| Технология / Пакет | Назначение |
|-------------------|------------|
| **Unity Localization** | Гибкая система локализации текста, изображений и аудио. Позволяет переключать язык без перезапуска игры. |
| **FMOD Studio** | Профессиональное аудио-миллирование. Используется для создания сложных звуковых событий, эмбиента и музыки с параметрическим управлением. |
| **UniTask** | Асинхронное программирование без корутин. Используется для загрузки ресурсов, HTTP-запросов и любых операций, требующих ожидания. Обеспечивает высокую производительность и читаемость кода. |
| **DOTween** | Создание плавных анимаций: движение UI, масштабирование объектов, затухание и другие эффекты. Легко интегрируется и позволяет делать анимации без лишнего кода. |
| **HTTP (GET/POST)** | Обмен данными с сервером. GET – получение списка рекордов, POST – отправка результата игрока. Реализовано с использованием `UnityWebRequest` и UniTask для асинхронности. |
| **Самописный генератор кода FMOD (на базе Scriban)** | Инструмент, анализирующий банки FMOD и создающий C# классы с константами для всех событий и параметров. Генерация шаблонов выполняется с помощью **Scriban** — современного шаблонизатора для .NET. Это позволяет гибко формировать код, избегая ручного написания и ошибок. В итоге все звуки вызываются через константы в классе `AudioSystem` без магических строк и сериализованных полей. |
